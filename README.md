# Artifactory organization profile

Public identity assets and the organization overview for [Artifactory-tech](https://github.com/Artifactory-tech).

- `profile/README.md`: public GitHub organization overview.
- `profile/assets/`: animated SVG header, static alternative and organization avatar.
- `brand-source/`: crystal geometry and relevant styles from the Artifactory website, revision `a13d1eb603ccd67416c59c5938da60698e6efb10`.
- `build-brand.mjs`: rebuild the SVG headers with `node build-brand.mjs`.

The crystal uses the existing website geometry and CSS animation. The SVG is self-contained, runs without JavaScript or external resources, and respects reduced motion. The square avatar is static.

Company and project information: [artifactory.tech](https://artifactory.tech/en/).

Brand artwork is provided for Artifactory’s own profile. No general license to reuse the Artifactory name or marks is granted by this repository.
